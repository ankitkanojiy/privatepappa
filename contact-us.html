PrivateVault support

Describe the issue, not your secrets.

Send enough technical context to make the problem reproducible. Never send a vault password, backup password, derived key, private file, or unredacted personal data.

Email reply@privatepappa.in
01

Include useful context

  • PrivateVault or PrivateVault PRO
  • App version and Android version
  • Device make and model
  • Exact action and observed result
  • Whether the issue repeats with disposable test data
02

Keep sensitive data out

  • Do not send vault or backup passwords
  • Do not send encryption keys or verifier values
  • Do not attach private vault files
  • Redact filenames, paths, and personal details
  • Use replaceable test content for demonstrations
03

Understand recovery limits

PrivateVault has no developer-operated vault server, remote decryption service, or master recovery key. Support cannot recover a forgotten vault or backup password or reconstruct encrypted data that has already been lost.

Faster diagnosis

A concise report is more useful than a large data dump

For a functional issue

List the screen, action, expected result, actual result, and whether restarting changes the outcome.

For a backup issue

State whether the backup was newly created or older, its approximate size, and the displayed stage. Do not alter its header or send the backup unless explicitly and safely arranged.

For a security report

Explain the violated security boundary and a reproducible sequence using disposable data. Avoid testing against anyone else’s data or device.

For a viewer issue

State the file type, approximate size, edition, and whether another non-sensitive test file of the same type behaves differently.

Before emailing

The answer may already be documented.

Review the technical FAQs for encryption, biometrics, backups, edition differences, and export boundaries.
